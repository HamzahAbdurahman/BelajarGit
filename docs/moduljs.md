# Dokumentasi JavaScript Dasar — Modul 01

## 1. Tujuan
Menguasai tipe data, variabel, operator, console, dan logika dasar Task Manager.

## 2. Cara Menjalankan
- Browser: buka index.html, lihat DevTools → Console.
- Node.js: `node src/js/01-hello.js`

## 3. Daftar File
| File | Topik | Cara jalan |
|---|---|---|
| 01-hello.js | Hello World | `node src/js/01-hello.js` |
| 03-number.js | Number | `node src/js/03-number.js` |
| 11-task-manager.js | Study case | `node src/js/11-task-manager.js` |

## 4. Konsep yang Dipelajari
- Tipe data: number, boolean, string.
- Variabel: `let`, `const`, aturan penamaan.
- Operator: matematika, perbandingan, logika.
- Console: `log`, `warn`, `error`.

## 5. Log Error & Solusi
| Error | Penyebab | Solusi |
|---|---|---|
| ReferenceError | Variabel belum dideklarasikan/salah ketik | Cek nama variabel |
| TypeError const | Mengubah nilai `const` | Gunakan `let` jika perlu berubah |

## 6. Riwayat Git
- Commit pertama: `<hash pendek>`
- Commit terakhir: `<hash pendek>`
- Perintah cek hash: `git log --oneline`, `git rev-parse --short HEAD`
